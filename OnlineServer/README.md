# AO Online: servidor de sala privada

Servidor .NET 10 para la primera prueba cooperativa de Unity. Límite de once conexiones (anfitrión y diez amigos), clave aleatoria persistida sólo junto al ejecutable, mensajes JSON delimitados por salto de línea y protocolo versión 1.

El servidor sólo retransmite presencia, posición y chat. No reemplaza las reglas del servidor VB6 ni guarda personajes. Ejecutarlo dentro de Tailscale. El paquete y los pasos para anfitrión y amigos están en `../AO_Online/LEEME.md` después de publicar la versión de Escritorio.
